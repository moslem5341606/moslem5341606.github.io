# Moslem Uddin — academic website

Static academic website prepared for GitHub Pages. It has six pages: Home, CV, Publications, Education, Engagement and Contact.

## Publishing to an existing GitHub Pages repository

1. Review and back up any existing repository content.
2. Place `index.html`, the other HTML files and `style.css` at the repository root.
3. In repository Settings → Pages, publish from the main branch root if not already enabled.
4. Replace the monogram with your portrait and add your verified professional email, ORCID, Scholar URL, complete CV, DOI links and full publication details.

No build command or dependencies are required. This package intentionally contains no unverified awards, dates, affiliations, contact information or invented publication links.
